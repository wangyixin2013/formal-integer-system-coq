# Formal Integer Arithmetic and Number Theory in Coq

Formal development of integer arithmetic and number theory in **Coq**, built from a small set of axioms.

The project develops **100+ machine-checked lemmas and theorems**, covering integer arithmetic, divisibility, ordering, induction, prime factorization, and modular arithmetic.

## Highlights

- Built an integer system from minimal algebraic and ordering axioms
- Proved results including the division algorithm, induction, Gauss's lemma, and unique prime factorization
- Developed modular arithmetic and supporting results toward **Fermat's Little Theorem**
- Translated mathematical arguments into rigorous, machine-verifiable proofs

Coq · Formal Verification · Mathematical Logic · Number Theory
